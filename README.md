\# 🛒 Retail Sales Prediction \& Customer Segmentation



A Machine Learning project based on the \*\*UCI Online Retail II dataset\*\*.



This project combines \*\*Customer Segmentation\*\* and \*\*Retail Sales Prediction\*\* to analyze customer purchasing behavior and predict daily retail sales.



\---



\## 📌 Project Overview



The project has two main Machine Learning components:



\### 1. Customer Segmentation



Customers are grouped according to their purchasing behavior using:



\- RFM-based customer features

\- Data preprocessing

\- Log transformation

\- StandardScaler

\- Principal Component Analysis (PCA)

\- K-Means Clustering



\### 2. Sales Prediction



Daily retail sales are predicted using:



\- Feature engineering

\- Simple Linear Regression

\- Multiple Linear Regression

\- Polynomial Regression

\- MAE

\- RMSE

\- R²



The project also includes an interactive \*\*Streamlit dashboard\*\*.
